# A2 response template

Open `a2-review.tex` in Overleaf, or run `latexmk -pdf a2-review.tex` locally.
Replace the small grey prompts and bracketed text with your responses. Retain the
three summary headings. The executive summary, including its identifying header,
is at most two pages. Do not reduce the 11-point font or 1-inch margins.

For references, add sources to `references.bib` and use `\citep{key}` or 
`\citet{key}` (replace the placeholder reference by Carberry).

Submit one completed PDF to Crowdmark and LEARN Dropbox. Submit screencaps of
each question response to Crowdmark and the entire pdf to LEARN/Dropbox. You
do not need to submit latex source code.
