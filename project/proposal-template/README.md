# ECE750T project proposal template

Replace the bracketed prompts in `project-proposal.tex`, retain all eight question
headings, and add your citations to `references.bib`. The proposal is at most two
pages excluding references. Remove placeholder text; do not change the font size
or margins to fit more text. You may move or remove the supplied page break.

Build with `latexmk -pdf project-proposal.tex`, or upload this folder to Overleaf.
The bibliography is enabled. The template includes a clearly marked example
citation to Chouldechova (2017), which renders a References section. Replace
the example citation and BibTeX entry with sources relevant to your proposal.
The included PDF previews the template, with smaller question headings and a
footer reminding you of the two-page limit excluding references. Submit your completed PDF to both
Crowdmark and LEARN Dropbox; source files are not required for the proposal.

Released September 25, 2026. Consult the handout for the proposal deadline.
The dated weekly table uses the draft October 9–December 4 planning window.
This template is for the proposal; final-report instructions will be separate.
