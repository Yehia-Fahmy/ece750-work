## Implemented behavior

`GpuLease(canonical_checkout, *, owner, job, run_id)` is a context manager with `assert_held()`, `heartbeat()`, `lock_path`, and `metadata_path`. It resolves standard Git worktrees using the absolute common Git directory, so workers share the primary checkout's ignored `project/runs/shortcut-study/gpu.lock`. Explicit non-Git directories are supported for shared roots and CPU tests. Nonstandard Git common directories fail closed rather than guessing their primary checkout.

The stable lock file uses nonblocking exclusive `flock`; contention raises `LeaseBusyError`. Its inode is never replaced or deleted. Metadata in adjacent `gpu.lock.json` records owner, PID, host, job, run ID, canonical paths, acquisition time, heartbeat, and release status through atomic fsynced writes. Metadata is diagnostic: even a stale heartbeat cannot override the kernel lock. Closing the descriptor or process exit releases ownership. Forked children close their inherited descriptor and cannot claim or release the parent's lease. No process is signaled or killed.

`assert_supported_gpu()` performs only the read-only `nvidia-smi` name/UUID/total-memory query. It resolves the executable through `shutil.which("nvidia-smi")`, then uses only the fixed `/usr/lib/wsl/lib/nvidia-smi` fallback when that file exists and is executable. It invokes an argument list without a shell. It rejects missing, multiple, or unsupported devices and accepts the 8 GB NVIDIA GeForce RTX 3070 Ti, allowing the small total-memory accounting variation within 8,000–8,192 MiB. It returns `name`, `uuid`, and `memory_total_mib`; it neither starts a server nor allocates GPU memory. Acquiring the CPU-tested lease alone does not assert GPU availability; the operator must separately call this helper before inference.
