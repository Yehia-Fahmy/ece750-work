# Instructions for work in this extension

Read `README.md`, `DECISIONS.md`, `AGENT_GUIDE.md`, and your assigned work package before editing. This directory contains an additional study; historical research is protected by `preservation-manifest.json`. Do not alter, delete, relocate, or regenerate those protected files. Changes to historical work require a separate explicit researcher instruction.

All experimental actor and judge inference must run locally on the RTX 3070 Ti. No external inference, GPU, paid service, or remote generation. Public-source research and free checkpoint downloads are allowed; never overwrite original assets. The current planning pass authorizes documentation only, not experimental execution.

Future execution requires a researcher instruction to execute the plan. An executing orchestrator may delegate packages when the user authorizes agent orchestration. Workers edit only assigned paths, coordinate shared schemas, and leave integration and GPU ownership to their designated owners. No worker starts a GPU process without the shared lease. See `AGENT_GUIDE.md` for coordination and handoff rules.

Distinguish proposals, implemented features, validated features, and measured results. Do not fill missing evidence with plausible values. A model trace is observable generated text, not guaranteed faithful access to internal computation. Keep uncertain semantic judgments uncertain.

Run relevant checks before a handoff. Record commands, actual outcomes, artifact hashes, and remaining problems. Main-run changes require versioning and the frozen protocol's change policy; never repair a scientific result by silently rewriting its inputs.
